# Task Reminder AI — تطبيق تذكير المهام (Android)

تطبيق عربي بالكامل (RTL) لإدارة المهام اليومية، يرسل إشعارًا في الوقت المحدد حتى والتطبيق مغلق.
بلا حساب، بلا إنترنت (لا يطلب إذن INTERNET أصلًا)، بلا مكتبات خارجية — حجم صغير ويعمل على Android Go.

## المميزات
- إضافة/تعديل/حذف المهام، وإيقاف تذكير المهمة مؤقتًا (المفتاح في بطاقة المهمة).
- وقت دقيق (ساعة ودقيقة) + تكرار: مرة واحدة (بتاريخ) / كل يوم / أيام محددة من الأسبوع.
- إشعار: «حان وقت مهمتك! — ابدأ بمهمة «اسم المهمة» الآن» مع زرّي **تم ✓** و**تأجيل**.
- الشاشة الرئيسية: اليوم / المتبقية / المكتملة / كل المهام، مع شريط تقدّم.
- سجل الإنجاز: نسبة الإنجاز، عدد أيام الالتزام، السلسلة الحالية، وآخر 7 أيام.
- إعدادات: وضع داكن (أسود + أحمر داكن، الافتراضي) أو فاتح، مدة التأجيل (5/10/15/30)، إشعار تجريبي.
- ضغطة مطوّلة على مهمة = حذف سريع.

## بناء ملف APK

### الطريقة 1: Android Studio (الأسهل)
1. ثبّت Android Studio (Ladybug أو أحدث) وافتح هذا المجلد (`File > Open`).
2. انتظر مزامنة Gradle (تحتاج إنترنت أول مرة، وسيحمّل SDK 35 تلقائيًا).
3. `Build > Build Bundle(s) / APK(s) > Build APK(s)` ثم `locate`.
   الملف: `app/build/outputs/apk/debug/app-debug.apk`

### الطريقة 2: سطر الأوامر
متطلبات: JDK 17 وAndroid SDK (platform 35 + build-tools) ومتغير `ANDROID_HOME`.
```bash
./gradlew testDebugUnitTest      # اختبارات منطق التكرار والجدولة والإحصاءات
./gradlew assembleDebug          # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease        # app/build/outputs/apk/release/app-release.apk (مصغّر، موقّع ببصمة debug)
```

### الطريقة 3: بدون تثبيت أي شيء (GitHub Actions)
ارفع هذا المجلد إلى مستودع GitHub جديد؛ سيعمل `.github/workflows/build.yml` تلقائيًا (أو من تبويب Actions > Run workflow)،
وتجد الـ APK في **Artifacts** باسم `TaskReminderAI-apk`.

## التثبيت على الهاتف
1. انقل الملف إلى الهاتف (USB/واتساب/Drive).
2. افتحه واسمح بـ«التثبيت من مصدر غير معروف» لتطبيق الملفات/المتصفح.
3. أو عبر USB: `adb install -r app-debug.apk`.

## بعد أول تشغيل (مهم لعمل التذكيرات)
1. اسمح بالإشعارات (Android 13+ يسأل تلقائيًا).
2. أندرويد 14+: فعّل إذن **«المنبهات والتذكيرات»** (سيظهر شريط أحمر في التطبيق يأخذك للإعداد).
3. من الإعدادات داخل التطبيق: **«السماح بالعمل في الخلفية»** → اختر «غير مقيّد/Unrestricted».
4. اضغط **«إرسال إشعار تجريبي»** للتأكد، ثم أضف مهمة بعد دقيقتين وأغلق التطبيق لتجربة التذكير.

## القيود التقنية (متى قد لا يصلك الإشعار)
- **الإيقاف الإجباري (Force Stop)** من إعدادات التطبيق يمسح كل المنبهات في أندرويد ولا يُعاد جدولتها حتى تفتح التطبيق مرة أخرى — هذا سلوك النظام ولا يمكن تجاوزه.
- **سحب التطبيق من الأحدث** عادةً آمن، لكن بعض الشركات (شاومي/MIUI، هواوي، أوبو/ريلمي، فيفو، وأحيانًا سامسونج) تعامله كـ«إيقاف إجباري». فعّل «التشغيل التلقائي/Autostart» وعطّل «تحسين البطارية» للتطبيق (راجع dontkillmyapp.com).
- **إذن المنبهات الدقيقة** (Android 12+/14+): بدونه يستخدم التطبيق منبهات «تقريبية» قد تتأخر عدة دقائق في وضع Doze.
- **Doze وتوفير الطاقة**: المنبهات الدقيقة تُوقظ الجهاز، لكن «توفير البطارية الشديد» عند بعض الشركات قد يؤخرها.
- **إيقاف الإشعارات** للتطبيق أو لقناة «تذكيرات المهام»، أو وضع «عدم الإزعاج»، سيمنع الصوت/الظهور.
- **إعادة التشغيل**: يُعاد جدولة التذكيرات تلقائيًا عند اكتمال الإقلاع (قبل أول فتح لقفل الشاشة قد يتأخر قليلًا). كذلك عند تغيير الوقت/المنطقة الزمنية وبعد تحديث التطبيق.
- **سجل الإنجاز** يُحسب من المهام الحالية؛ حذف مهمة يحذف سجلها، وتعديل جدولها يغيّر الحساب بأثر رجعي.
- لا يوجد نسخ احتياطي سحابي عمدًا (الخصوصية): إلغاء تثبيت التطبيق يحذف بياناته.
- الاسم «AI» للعلامة التجارية فقط: لا يعتمد أي تذكير على ذكاء اصطناعي أو إنترنت.

## هيكل المشروع
- `Logic.kt` / `Task.kt`: منطق التكرار والتنبيه التالي والإحصاءات (بدون Android، ومغطّى باختبارات `LogicTest.kt`).
- `Scheduler.kt`: AlarmManager (`setExactAndAllowWhileIdle`). `Receivers.kt`: التنبيه، أزرار الإشعار، إعادة الجدولة بعد الإقلاع.
- `TaskDb.kt`: SQLite محلي. `Notifier.kt`: قناة وإشعارات. باقي الملفات واجهات.
